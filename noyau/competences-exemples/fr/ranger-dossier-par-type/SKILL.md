## Quand l'utiliser
Quand l'utilisateur demande de ranger, trier ou classer les fichiers d'un dossier selon leur type.

## Etapes
1. Planifier la mission : regarder le contenu, créer les sous-dossiers, déplacer, vérifier.
2. Lister le contenu du dossier pour identifier les types de fichiers présents (.png/.jpg = images, .pdf/.txt/.xlsx = documents, .mp3 = audio, etc.).
3. Annoncer le plan de classement en une ou deux phrases avant d'agir.
4. Créer un sous-dossier par type présent (noms simples : Images, Documents, Audio, Vidéo).
5. Déplacer chaque fichier dans son sous-dossier (déplacer, jamais supprimer).
6. Vérifier le résultat avec une arborescence du dossier et confirmer que tous les fichiers sont classés.

## Pieges a eviter
- Ne jamais supprimer de fichier : ranger signifie déplacer.
- Regarder le contenu AVANT de proposer le classement, et l'annoncer à l'utilisateur.
- Ne créer que les sous-dossiers nécessaires (pas de sous-dossier vide).
- Vérifier à la fin qu'aucun fichier n'est resté à la racine.
