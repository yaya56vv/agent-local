## When to use it
When the user asks to sort, organize, or classify files from a folder by type.

## Steps
1. Plan the mission: examine the content, create subfolders, move, verify.
2. List the folder contents to identify file types present (.png/.jpg = images, .pdf/.txt/.xlsx = documents, .mp3 = audio, etc.).
3. Announce the sorting plan in one or two sentences before acting.
4. Create a subfolder for each type present (simple names: Images, Documents, Audio, Video).
5. Move each file to its subfolder (move, never delete).
6. Verify the result with a folder tree and confirm all files are sorted.

## Pitfalls to Avoid
- Never delete files: sorting means moving.
- Examine the content BEFORE proposing the sorting plan, and announce it to the user.
- Only create necessary subfolders (no empty subfolders).
- Check at the end that no file is left at the root.
